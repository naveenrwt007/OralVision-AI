# OralScan AI

OralScan AI is an explainable deep-learning-based web application for
preliminary oral cancer risk screening using smartphone images.

## Initial Screening Categories

- Normal
- Potentially Precancerous
- Suspicious

## Technology Stack

- React
- FastAPI
- PyTorch
- EfficientNet-B0
- OpenCV
- Grad-CAM
- MongoDB

## Important Disclaimer

This system provides preliminary oral-health risk screening only.
It does not diagnose or rule out cancer. Cancer confirmation requires
clinical examination and, when indicated, biopsy and histopathological
assessment by qualified medical professionals.
